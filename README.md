# hotel-booking-cancellation-prediction
Analytics project focused on predicting hotel booking cancellations and improving revenue risk management using machine learning.
## Project summary
Built an end-to-end ML pipeline to predict hotel booking cancellation
probability — directly analogous to credit Early Warning Systems (EWS)
and AML transaction risk scoring frameworks used in banking.

## What this covers
- Exploratory Data Analysis on 9,000+ booking records
- Decision Tree & Random Forest model comparison
- 3-tier risk classification (Low / Medium / High risk)
- Business recommendations: pricing strategy, deposit policy,
  overbooking controls

## Key result
Decision Tree (Pruned) selected as final model: 84.45% test accuracy,
73.06% recall. Chosen for interpretability and real-time deployment fit.
