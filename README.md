# Hotel Booking Cancellation Risk Prediction

Personal Data Analytics Project (2026)
Assessment in progress.

## Project summary
Built an end-to-end ML pipeline to predict hotel booking
cancellation probability — directly analogous to credit Early
Warning Systems (EWS) and AML transaction risk scoring
frameworks used in banking.

## What this covers
- Exploratory Data Analysis on 9,000+ booking records
- Decision Tree & Random Forest model comparison
- 3-tier risk classification (Low / Medium / High risk)
- Business recommendations: pricing strategy, deposit
  policy, overbooking controls

## Key result
Decision Tree (Pruned) selected as final model: 84.45% test
accuracy, 73.06% recall. Chosen for interpretability and
real-time deployment fit.

## Tools used
- RapidMiner (model building, Decision Tree, Random Forest)

- Microsoft Excel (EDA and data exploration)
